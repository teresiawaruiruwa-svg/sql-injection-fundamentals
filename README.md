# SQL Injection Fundamentals

A technical portfolio case study documenting practical exercises completed in HTB Academy's SQL Injection Fundamentals module.

> Authorized training-lab work only. Do not test systems without explicit permission.

## Coverage
- MySQL and MariaDB foundations
- Query logic, authentication predicates, quoting, comments, and parentheses
- UNION-based result analysis and output-position discovery
- INFORMATION_SCHEMA metadata enumeration
- LOAD_FILE and INTO OUTFILE: permissions and impact conditions
- Black-box assessment methodology
- Troubleshooting and secure coding remediation

## Project structure
- `docs/` — technical notes organized by topic
- `notes/` — assessment analysis and evidence register
- `evidence/screenshots/` — lab screenshots
